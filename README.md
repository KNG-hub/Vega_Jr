# Vega_Jr.
A simple and basic assistant chatbot using Python's Tkinter. Not the best but not the worst at his job, still a project in development so expect updates and new versions

Vega Jr. is a personal desktop assistant built with Python and Tkinter.
Current Version: V0.9.0 Beta
Features:
- Greetings
- Joke System
- Coin Flip
- Mood System
- Favorite Game Memory
- Homework Helper
- Grade Calculator
About
Vega Jr. is a personal project created by myself and the help of Copilot and other Ais. It is still in active development, so expect updates, improvements, and future versions.

(Clarification: No I didn't copy the code or asked the AIs to give me the code. I'm learning self-taught programming and, using AI as an assistant in this project not as a tool to build it or make it but, using it to make some concepts clearer and, help with debugging.)
